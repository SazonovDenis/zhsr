# zhsr: термины и сокращения

| Термин                        | Значение                                                            |
|-------------------------------|---------------------------------------------------------------------|
| Депо приписки                 | Депо, за которым числится вагон (не расположение вагона)            |
| Парк                          | Категория вагона по годности к работе: рабочий, нерабочий, исключён |
| Парк отстоя                   | Место расположения вагонов при станции, как депо (не категория)     |
| Рейс                          | Поездка поезда. Как правило туда и обратно.                         |
| Разовый маршрут               | Маршрут поезда без расписания                                       |
| Станция включения, исключения | Где вагон вошёл в состав рейса и где вышел из него                  |
| `ЛНП`                         | Начальник пассажирского поезда                                      |
| `ПЭМ`                         | Поездной электромеханик                                             |
| `ТО`                          | Техническое обслуживание                                            |
| `ТОР`                         | Текущий отцепочный ремонт                                           |
| `ТР-1`, `ТР-2`                | Текущий ремонт первого, второго объёма                              |
| `ДР`                          | Деповской ремонт                                                    |
| `КР`                          | Капитальный ремонт                                                  |
| `ЕТР`                         | Единый технологический ремонт                                       |
