## Система Жолсерік

`Система` Жолсерік (Zholserik) - новая версия системы для автоматизации учёта, эксплуатации и технического
обслуживания пассажирских вагонов и работы поездных бригад.

## Сборка документации

Документацию в каталог `_site` собирает скрипт `build-doc` в корне проекта. Скрипт также переводит схемы draw.io
(`doc/*.drawio`) в файлы png рядом с исходником: `location-transitions.drawio` - в `location-transitions.png`.

Для сборки нужны:

- утилита `build-doc` - каталог задаёт переменная `BUILD_DOC`, по умолчанию `../../build-doc` от корня проекта;
- утилита `doc-db` - каталог задаёт переменная `DOC_DB`, по умолчанию `../../doc-db` от корня проекта;
- draw.io desktop с командой `drawio` в `PATH` - для перевода схем в png.
