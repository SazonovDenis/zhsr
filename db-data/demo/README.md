# Демо-данные

Загружает `./env-reset --demo` (`install/db-reset --demo`) после начальных данных `db-data/default`: файлы по порядку имён, `<nn>-<таблица>.tsv` - в
таблицу, `*.sql` - выполняются. Здесь всё, что у каждого заказчика своё: сотрудники, депо, парки отстоя, неисправности,
вагоны, маршруты, рейсы, заявки. На рабочей БД этих данных нет.

Время записано на момент 2026-10-29 07:05; `99-shift-time.sql` сдвигает его к моменту загрузки, поэтому данные всегда
свежие: рейс 002 Алматы - Астана в пути, заявки поданы час назад.
