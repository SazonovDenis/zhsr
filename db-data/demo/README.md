# Демо-данные

Загружает `./env-reset --demo` (`install/db-reset --demo`) после начальных данных `db-data/default`: файлы по порядку
имён, `<nn>-<таблица>.tsv` - в
таблицу, `*.sql` - выполняются. Здесь всё, что у каждого заказчика своё: сотрудники, депо, парки отстоя, неисправности,
вагоны, маршруты, рейсы, заявки, шаблоны чек-листов. На рабочей БД этих данных нет.

Время записано на момент 2026-10-29 07:05; `99-shift-time.sql` сдвигает его к моменту загрузки, поэтому данные всегда
свежие: рейс 002 Алматы - Астана в пути, заявки поданы час назад.

## Источник

tsv здесь - источник данных: правятся вручную, без нужды не меняются. Первоначально собраны (2026-11-03) из заготовок
API фронта (`zhsr-web/src/api`, главный источник) и выгрузки демо-базы zholserik
(`../zholserik/db/zholserik-demo.sql`); сборщик удалён.

Шаблоны чек-листов (`23`-`28`) собраны (2026-11-10) из zholserik: "Проверка: топ нарушений" и "Проверка качества уборки" - из
`tools/checklists/generate.py` (классификатор заказчика); "Приёмка вагона", "Медосмотр", "Инструктаж" - по ТЗ zholserik
(Ф-ПРВ-03, Ф-ПЕР-03, Ф-ПЕР-06), границы показателей медосмотра - демонстрационные. Казахские и английские тексты -
черновые, как и в zholserik.

Ссылки на станции - id из `db-data/default/01-station.tsv`: после новой сборки станций из OSM их надо перепривязать.
