# Демо-данные

Загружает `./env-reset --demo` (`prepare/db-reset --demo`) после начальных данных `db-data/default`: файлы по порядку
имён, `<nn>-<таблица>.tsv` - в
таблицу, `*.sql` - выполняются. Здесь всё, что у каждого заказчика своё: сотрудники, депо, парки отстоя, неисправности,
вагоны, маршруты, рейсы, заявки, шаблоны чек-листов. На рабочей БД этих данных нет.

Фото демо-заявок, чек-листов и описей - в `img/` (источники и лицензии - `img/README.md`); `./env-reset` кладёт
их в хранилище файлов (`prepare/files-img`), ссылки на них - `22-repair_request_photo.tsv`,
`34-check_list_value_photo.tsv`, `37-equip_list_value_photo.tsv`.

Время записано на момент 2026-10-29 07:05; `99-shift-time.sql` сдвигает его к моменту загрузки, поэтому данные всегда
свежие: рейс 002 Алматы - Астана в пути, заявки поданы час назад. `99-db_info-demo.sql` ставит признак демо-БД
(`db_info.demo`): страница входа показывает быстрый вход.
